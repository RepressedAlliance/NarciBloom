# 安装与恢复

NarciBloom 为 Steam《Narcissu 10th Anniversary Anthology Project》（应用 ID `426690`）提供可调字号。当前安装包属于开发预览：自动识别、安装与恢复检查不等于逐章游玩验证，具体范围见[兼容性说明](COMPATIBILITY.md)。免费版《Narcissu 1st & 2nd》是另一款游戏，不适用本安装器。

## 选择安装包

| 安装包 | 适合谁 | 使用的输入 |
|---|---|---|
| 独立字体补丁 | 希望保留当前剧情语言、只调整阅读体验 | 本地已安装且被识别为支持的日文、英文或中文故事 |
| 中文整合包 | 希望安装风铃汉化组 PC v1.1 并增加可调字号 | 自有 Steam 游戏，以及原样保留的 PC v1.1 汉化 RAR |

两个包共用安装界面与恢复机制，不包含游戏本体，也不获取未购买的 DLC。中文整合包由独立工具在本地读取原汉化包并生成改动，不将修改后的汉化程序当作汉化组官方更新。汉化署名、原包与发布方式见[汉化来源说明](TRANSLATION.md)。

汉化：**风铃汉化组**；字体与平台适配：**NarciBloom**。原汉化请以[官方发布页的 PC 补丁 v1.1](https://www.rainlain.com/index.php/2024/11/01/2567/)为准，页面另列的移植版 v1.2 不属于本次输入。

## Windows

1. 在 Steam 中安装游戏及自己拥有、准备游玩的故事，完全退出游戏。
2. 将下载的对应 **Windows 安装包完整解压**到一个文件夹，打开其中的 `.exe`。保留包内附带的文件，不要只移动启动程序。
3. 安装器会查找 Steam 游戏目录。若未找到，点击「选择目录」，选择十周年合集的游戏根目录，也就是包含 `narci_onetwo` 等故事子目录的文件夹。
4. 检查列出的故事，保留需要安装的勾选项。未安装的故事不会补装；未识别或不支持的版本会明确显示并禁止勾选。
5. 中文整合包会自动使用启动程序旁的原汉化 `N10 ver1.1补丁.rar`。若没有附在同一目录，使用「选择 RAR」指定自己的原包。不要预先运行或覆盖汉化 EXE。
6. 点击「安装 / 更新」，等待完成，再从 Steam 启动游戏。

字体包按系统语言选择日文、英文或中文界面，也可在右上角切换。切换安装器界面语言不翻译游戏剧情；中文整合包默认使用中文界面。

可选的「默认字体」只指定本次构建所用的现有字体，不安装字体、不改变系统区域设置。留空时会自动选择适合文本语言的本机已装字体；如仍出现缺字或乱码，可重新打开安装器选择自己已装的对应语言字体并更新。游戏内字号档位与入口见[项目首页](../README.md)。

## SteamOS / Steam Deck

使用发行页提供的 **SteamOS / Linux 原生安装包及其可执行入口**。Windows `.exe` 不是 SteamOS 原生程序，不应把它当作 Linux 入口双击，也不需要将安装器放入游戏的 Proton 兼容前缀。

在桌面模式下完整解压 SteamOS 包，打开其中的原生安装程序；如文件管理器提示文件尚不可执行，在属性中允许执行。后续目录检查、故事选择和「安装 / 更新」与 Windows 相同。中文整合包的原汉化 RAR 同样放在启动程序旁，或通过界面选择。

安装界面适合 1280×800 画面，支持鼠标以及 Tab、方向键、空格和 Enter。手柄须映射为鼠标或这些键盘按键；安装器没有独立的原生手柄输入层。安装完成后可返回游戏模式，通过 Steam 的原游戏入口启动。

## 更新、卸载与冲突

再次打开安装器并点击「安装 / 更新」即可更新。构建会读取安装记录保留的原始输入，避免把已经修补的文件反复当作原版。未知版本、缺少输入或恢复冲突不会被静默跳过，原因会显示在界面与日志中。

安装器在游戏根目录的 `.narcibloom` 中保留原文件备份、受管文件清单和事务记录。保留这个文件夹；不要用 Steam 文件验证替代补丁卸载，也不要先手动删除备份。此记录可能含本地游戏或汉化内容，不应上传到公共仓库或随反馈整目录分享。

点击「卸载并恢复」会恢复本安装器替换前的文件，并移除它新增且仍未发生变化的文件。`savedata`、`save_chs` 及其他受保护存档或设置文件不会被安装器覆盖。卸载不删除自己的 Steam 游戏或 DLC，也不会自动清空备份。

如果用户、Steam 或另一补丁随后修改了受管文件，安装器会停止覆盖并报告冲突。请保留现场，复制日志用于排查；不要为了继续安装而删除记录、伪造版本或强行覆盖。安装过程遇到普通写入失败时会尝试回到操作前状态；被中断的事务会在下一次安装或卸载前恢复，若恢复本身发现后续变化也会停止。

任务在后台执行，进行期间请保持游戏关闭，等待完成后再退出窗口。发生错误时使用「复制日志」，附上故事、游戏语言和现象反馈；分享前检查日志是否包含个人路径。安装记录、文件检查和一次启动成功均不能证明所有篇章与演出已经验证。
