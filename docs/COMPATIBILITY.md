# 兼容性与实测范围

更新于 2026-10-20。区分“已实现”“离线检查”和“实际游玩”，不将一次开头测试等同于全篇验证。

## 当前目标

- 游戏：Steam《Narcissu 10th Anniversary Anthology Project》，应用 ID `426690`。
- 语言：本地 Steam 日文输入，以及当前测试设备上的简体中文汉化；文件标识与汉化来源线索见 [VERSIONS.md](VERSIONS.md)。
- 实测设备：Steam Deck；Proton 7.0；游戏画布 800×600，窗口模式。
- Windows 增加独立副本的有限运行检查，详见下文；其他版本和兼容层尚未验证。
- 免费版《Narcissu 1st & 2nd》属于不同发行版本，不在当前支持声明内。

## Windows 原版／汉化对照（2026-10-20）

使用独立游戏副本，不复制个人存档，也未覆盖 Steam 安装或 Deck 现场。

- 日文 1＋2：CP932 日文新增菜单、六档显示、当前值、从 36 切换到 44，以及一代开头的两行日文正文已目视检查。
- 汉化 1＋2：从保存的原始汉化程序重新提取并构建，中文新增菜单、六档显示、当前值、从 36 切换到 44，以及一代开头的两行中文正文已目视检查。
- 日文 Iris：使用 `en` 的 ASCII 新增菜单，设置页六档控件、当前值及从 36 切换到 44 已目视检查；指定已安装的 `UD Digi Kyokasho N` 为默认字体后，重启时的日文新增菜单、44 当前值及序章首句日文正文也正常。此项不验证 Iris 多行长句或其他附加篇章的当前菜单。
- 五个日文模块以 `ja`／`en` 新增菜单分别完成构建。这里的 `en` 只是菜单语言，不证明 Steam 英文版可用。
- 扩展后的六项源码测试覆盖三种菜单语言的六档选择、当前值、控件边界、CP932／GBK 文案、原指令地址及可选默认字体配置；本次默认中文覆盖包与改动前构建逐字节相同。

以上不是全篇验证，也未验证所有模块、所有字号的 Windows 游玩。Windows 中文系统下日文程序的系统窗口标题和退出提示仍会乱码，1＋2 的新增日文菜单及已检查正文正常。本次没有更改系统区域设置。

Iris 曾在默认字体下出现正文和设置页动态日文乱码，停用字体补丁后也可复现；在游戏内选用现有日文字体 `UD Digi Kyokasho N` 后，原版正文恢复。构建时用 `--font-family` 指定该字体可保留正确的初始化字体，重启后的日文新增菜单已验证。该现象与原版字体／字符集环境有关，不能归为通用转区问题已经解决；其他设备应选择当地已安装且适合日文的字体。`en` 的 ASCII 菜单本身不解决正文乱码。

## 已知限制

- 图片内的按钮和标题不随字号变化；这不是对整个画面的等比放大。
- 个别文本模式仍使用游戏原有布局；尚未遍历所有长句、历史记录和特殊演出。
- 1＋2 的修正针对确定的脚本结构和 DLL 指令，遇到不匹配结构应停止，不能强行修改。
- 当前没有安装、升级与卸载的普通玩家入口，也没有验证从任意已修改版本重复构建的行为。
- 原版与汉化版需要分别构建；1＋2 汉化额外使用虚拟文件及翻译表适配。先装字体后覆盖汉化不能保证继续生效，须按对应输入重新构建。当前没有自动识别或安装顺序处理。
- 1＋2 汉化适配的原字体窗口使用简短英文标签，游戏设置和新增字号菜单保持中文。
