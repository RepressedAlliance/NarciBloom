# 兼容性与实测范围

更新于 2026-10-20。当前为开发预览。构建成功、安装恢复检查、游戏启动与短场景实测分别记录；尚未逐章验证全部剧情、演出和字号。

## 支持的输入与平台

- 游戏：Steam《Narcissu 10th Anniversary Anthology Project》，应用 ID `426690`；免费版《Narcissu 1st & 2nd》是另一发行版本，不适用。
- 故事：1＋2、姬子后日谈、小小的鸢尾花（Iris）、Zero、Sumire。只处理本机已安装的故事，不下载或解锁 DLC。
- 输入：已识别的五模块 Steam 日文、Steam 英文，以及风铃汉化组 PC v1.1，共十五种模块／语言组合。识别标记见 [source-profiles.json](source-profiles.json) 与 [translation-source.json](translation-source.json)；未知版本及相关资源冲突会停止处理。文件标记不是来源真实性或安全性认证。
- 安装器：Windows 与 SteamOS／Linux 各有原生入口；SteamOS 安装器无需 Proton，游戏仍使用其 Windows 引擎及 Proton。安装与恢复方法见 [INSTALLATION.md](INSTALLATION.md)。

Fonts 保留受支持输入的当前剧情语言；Chinese 从 PC v1.1 透明安装材料在本机生成中文与相同字体功能，也继续接受受支持原 RAR。中文来源、署名和分发边界见 [TRANSLATION.md](TRANSLATION.md)。

## 分页候选的当前边界

候选在文本将超出当前可见区域前等待，继续后清页显示后文；保留原字号、打字动画和舞台布局。日文 Iris／Sumire、英文 1＋2 的已知坏例已有分页后完整显示的正向结果；中文 Iris 也在序章开头有限抽样中观察到满页等待、点击后续写同条译文尾部。

新增分页等待期间暂不开放设置与历史记录，以免替换尚未显示完的段落。Windows 日文 Iris 的最终入口保护已抽样确认：F9 被忽略，右键菜单选择日志后返回同一满页，继续点击仍能完整显示余文。该限制只在新增的页内等待期间生效，不是任意时刻都能使用所有菜单。

同一 Iris 样本中，F2 在空槽保存、继续至尾页后用 F3 读档，恢复到前一个原生短段的自然等待点，随后 F9 设置与右键日志均能正常打开，未遗留菜单锁。**新增分页位置不能精确保存／恢复，读档可能需要重读当前段。** 这是一次短样本结果，不代表所有存档点或自动保存通过。Sumire 未重复最终入口保护全流程，快速跳过与自动播放等行为仍待补测。

日文 Iris 曾做一次 F8 短跳过，可继续且未锁死；中文 Iris 的最短 F6 Auto 探测可推进开头短段，单击后停止，静止等待正常。此类单次探测未覆盖分页边界、长时间自动播放或连续跳过，不构成这些功能的完整验收。

### 主分支自动分页补测（尚未随 preview.2 发布）

已复现并修正新增分页的自动等待问题：历史输入虽然不打开日志，却会让旧等待提前返回。修正只忽略新增自动等待中的两个历史输入分支，原自然停顿、语音计时、取消和快进代码不变。十五种受支持输入均核对了生成差异；相关源码测试共 151 项，147 项通过，4 项因平台条件跳过。

Windows 日文 Iris 使用只保留原开头两段的独立测试场景，后续剧情全部移除；保留真实文本区域和等待实现，私有启动入口设置 44 档及相同自动速度，直接进入样本。这不是章节选择菜单或完整剧情测试。旧版在历史键输入后提前翻页，本页驻留 12.157 秒，短于原计时最低 13.5 秒；修正版在本页等待中接收同一输入后驻留 13.609 秒，再完整显示尾文。实际运行的等待资源与当前源码生成结果逐字节相同。

另将测试入口的自动速度放慢，观察到历史键输入后满页持续可读；PageDown 取消自动播放并前进至同段尾页，尾页在原计时期限过去后仍等待手动确认。首轮曾有一张即时截图空白，后续观察未复现持续空白，不能据此保证所有重绘情况。

正常读档路径也已在同一 Windows Iris 样本抽查：先在首段自然停顿用 F2 保存至空 QA 槽，再从下一段的自动分页等待按 F3。原菜单入口先取消自动播放，随后选择测试槽并确认，恢复首段自然停顿；原计时期限过去后没有再次清页。设置能重新打开且仍为44，返回后再次手动完整显示长段满页和尾文。此结果不代表在仍开启的自动计时器中直接注入加载，也不代表精确页内存档或个人旧档兼容。

连续快进使用另一个独立空存档副本，只保留原开头两段，随后追加有终点的2,048条中性编号段，真实后续剧情不可达。通过实际菜单应用44档后，F8强制快进，正文左键单击停在编号1171；再次观察仍是同一满页。手动继续后尾文完整，再确认只进入编号1172，逐字显示恢复。首轮用PageDown没有停止强制快进；核对原生路径确认它不是这里的取消入口，不能把这当作分页缺陷，也不能以到达测试终点冒充中途停止成功。

上述是 Windows 日文 Iris 的有限场景与中性压力测试，游戏均正常退出，没有通关。带语音长段、英文1＋2外置菜单结构、其他模块及SteamOS对应交互仍未全部覆盖。

## Steam Deck 游戏实测

此前在 Deck 的 Proton 7.0、800×600 游戏画布与窗口模式下，已检查 1＋2 的字号菜单、当前值、一代 44 档自动换行／连续多行、二代 36 档多行及重启保留字号。这是特定版本和短场景的历史结果，不覆盖当前十五种输入及最新分页候选。

本轮实机为 SteamOS 3.8.13、glibc 2.41，游戏测试使用 Proton 7.0 与独立前缀。未经手工修改的新前缀中，`HOST_LC_ALL=ja_JP.UTF-8` 可使日文原版到达标题；中文 Iris 使用 `HOST_LC_ALL=zh_CN.UTF-8` 启动。此启动对照不代表安装器已自动设置 Steam 启动选项，处理方式见安装说明。

中文 Iris 已检查 44 当前值及高亮、开篇两行正文，以及正常退出确认。Windows 触发分页的 33 字译文，在本机自动选择的 `Noto Sans CJK SC` 下恰好能排进两行，未触发分页；不能把两平台的字体度量视为相同。

为验证 Deck 上的真实引擎分页，只在独立副本中将这一条译文临时替换为 87 字中性测试文字，脚本及其他译文不变。实测满页保持、F9 暂不可用、继续后尾文完整、原生停顿点设置恢复且仍为44；正常退出后已逐字节恢复原译文表。这是**合成长段压力测试**，不是原剧情长段或全篇通过。临时 gamescope 焦点状态也已恢复。

原生 GUI 的五部中文安装／卸载已通过，实际发布包的检查结果另见对应发布说明。其他 Proton 版本与兼容层、长期游玩、分页边界上的自动播放／连续跳过没有完整覆盖。

Linux 构建的实际 ELF 需要最高数值版本 `GLIBC_2.38`，另使用 `GLIBC_ABI_DT_RELR`。除随包运行库外，还依赖主机的 X11、Xft、Xss、fontconfig、bz2、lzma、mpdec、uuid 及 libarchive 等库；实测主机具备这些库。仅满足 GLIBC 数字下限不足以证明任意 Linux／SteamOS 版本兼容。

## 字体与原生窗口文字

安装器可自动选择本机已有且适合当前文本语言的字体，也可手动指定。Windows 日文 Iris 曾因默认字体／字符集环境出现正文与设置页乱码；选用已安装的 `UD Digi Kyokasho N` 后，已抽样正文与重启后的新增菜单正常。其他设备仍需有适合相应语言的字体；ASCII 菜单不能解决正文缺字或乱码。

已处理支持输入的固定菜单／对话资源；Windows 本轮抽样的退出确认显示为可读的 `Exit the game?`。部分字体窗口使用简短 ASCII 标签，游戏剧情与中文字号菜单保持中文。设置页的字体名称仍可能被原有字段截短。

**preview.1 的 Windows 中文五部主窗口标题乱码已在 preview.2 修正。** 后续检查找到此前按扩展名搜索遗漏的 `majiro.env` 独立 `TITLEBAR` 字段；现在只替换该字段，以完整英文作品名显示，并按引擎规则用 `|` 编码空格。其他环境字段、注册表保存位置、剧情及存档描述逐字节保留，不修改系统区域。

Windows 五部中文均已实际启动到标题画面，完整作品名可读；Iris 还检查了中文设置页、当前44及原生字体选择窗口，正常退出。十个真实日文／英文输入的标题字段及构建检查通过。这里验证的是标题栏修复，不代表全部演出或其他动态窗口文字均已遍历。

### 主分支日文存读档界面修正（尚未随 preview.2 发布）

姬子、Iris、Zero 的旧日文引擎使用默认字符集绘制存档名称和界面提示，正文却使用 Shift-JIS；非日文系统上可能出现正文正常、存读档提示乱码的情况。现在仅将这三个已识别引擎的界面字符集字段改为 Shift-JIS。较新的日文 1＋2／Sumire 已有明确的日文字符集，五部英文使用自己的 ANSI 字符集，均严格校验后保留；中文构建及保留中文的字体更新路径不使用这一适配。

十个真实原版输入均已生成并解析检查：三个旧日文引擎各只改变一个界面字符集字节，另外七个不改变此字段。Windows 日文 Iris 实际确认既有测试槽名称、保存完成与读取确认提示恢复正确日文，正文和固定退出提示正常；验证候选与正式后端生成结果逐字节一致。完整源码检查共157项，153项通过、4项因平台条件跳过。这里修正的是界面绘字，不重写存档文件或原描述字节，不改变系统区域，也不代表所有动态窗口文字都已遍历。

## 其他限制与反馈

- 图片内的按钮和标题不随字号缩放。
- 尚未遍历全部文本模式、长句、历史记录与特殊演出；自动检查不能保证所有字体和所有字号都无裁切。
- 仅适配已确认的脚本、PE／DLL 结构与汉化版本，遇到不匹配输入应停止。不要在安装后另行覆盖汉化；通过安装器更新，以保留正确资源顺序与恢复记录。
- 未完成长期游玩、全篇存读档、自动播放／跳过及所有平台组合验收。
